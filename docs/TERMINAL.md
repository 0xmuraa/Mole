# TERMINAL

Concept for the future Underground Terminal layout. Nothing here is built yet — this documents the intended layout.

## Layout

```
┌───────────────┬───────────────────────────────┬───────────────┐
│               │                                 │               │
│  LEFT         │  CENTER                          │  RIGHT        │
│  Token /      │  Large animated underground     │  Surface      │
│  wallet       │  network                         │  activity     │
│  intelligence │                                   │               │
│               │                                   │               │
├───────────────┴───────────────────┬───────────────┴───────────────┤
│  BOTTOM LEFT                       │  BOTTOM RIGHT                  │
│  Public chain logs                 │  MOLE audit / live analysis    │
│                                     │  events                        │
└─────────────────────────────────────┴─────────────────────────────┘
```

## Panels

- **Left — Token / wallet intelligence**: details on a selected token or wallet.
- **Center — Underground network**: the main visualization. Multiple organic wallet regions (burrows) connected by animated tunnels, representing movement and relationships as they're detected.
- **Right — Surface activity**: what's currently visible on the surface (price, volume, trending), for comparison against what's happening underground.
- **Bottom left — Public chain logs**: raw public onchain activity feeding the system.
- **Bottom right — MOLE audit / live analysis events**: a live log of what MOLE itself is detecting and flagging.

## Center visualization

The centerpiece of the terminal. Multiple organic, burrow-shaped wallet regions, connected by animated tunnels that represent movement between them. This is where Fresh Dirt, Tunnels, Burrows, and MOLE Signals come together into a single live picture.
