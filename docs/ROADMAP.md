# ROADMAP

A phased development roadmap. No dates. No promised outcomes.

## Phase 01 — Identity

Brand, mascot, visual language, vocabulary. Establish what HYPERMOLE looks and sounds like before building anything functional.

## Phase 02 — Website

Public-facing homepage introducing HYPERMOLE, the seismic metaphor, and the product vision.

## Phase 03 — Terminal Prototype

A working prototype of the Seismic Terminal layout and the central animated network visualization, using placeholder or simulated data explicitly labeled as such.

## Phase 04 — Data Integration

Connect the terminal to real public onchain data sources for Robinhood Chain.

## Phase 05 — Product Expansion

Build out Tremors, Trace Inspector, Epicenters, HYPERMOLE Signals, and Surface Receipts as real, data-backed modules.

## Phase 06 — Token Integration

Integrate the HYPERMOLE token once it exists.

The official contract address will only be added once a real deployment exists.
