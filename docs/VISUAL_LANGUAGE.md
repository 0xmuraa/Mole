# VISUAL LANGUAGE

Initial design system for MOLE. This will evolve as the product gets built.

## Mascot

- Simple pixel-art mole.
- Clean 16-bit feeling.
- Friendly and memorable, not realistic.
- Should work without a background (transparent, drops cleanly onto any surface).
- Planned states: idle, digging, scanning, alert.

We already have a preferred pixel mole visual and will provide the final mascot asset manually. See [public/assets/README.md](../public/assets/README.md).

## Design principle

The mascot is pixel-art. The product around it is not. The UI itself should stay modern and clean — dark panels, clear type, purposeful color — rather than turning the whole product into a retro game. Pixel-art is a character choice for the mole, not a UI theme.

## Motifs

- Underground tunnels connecting nodes.
- Burrows as organic, rounded clusters.
- Glowing nodes for wallets and activity.
- Warm, dim, dug-in tones — dark brown and black grounded by amber and gold accents.
